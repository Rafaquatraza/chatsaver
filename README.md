# ChatBox 💬

Link: https://chatsaver-nx3n.onrender.com/ 

A simple real-time style chat application built using **Node.js**, **Express.js**, **MongoDB**, and **EJS**. The project demonstrates CRUD operations, server-side rendering, and database integration for managing chat messages.

---

## 🚀 Features

* Create new chat messages
* View all chats
* Edit existing messages
* Delete chat messages
* MongoDB database integration
* Server-side rendering using EJS
* RESTful routing
* Responsive and clean user interface

---

### Frontend
